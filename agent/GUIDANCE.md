# Curated coaching boundary

Runtime content is `backend/catalog/demo.json`; get_exercise_guidance returns one exact catalog entry by stable machine ID. The 18 records are developer-paraphrased from the public URLs stored in each entry. This is source-backed demo content, not a professional review, and must not be labeled as professionally approved. No occupancy sensing, observed-form feedback or automatic rep detection is implied.

Mat uses `setup`, `cue`, `mistake`, `muscles`, `troubleshooting` and `stop_conditions` from the retrieved record. It does not blend records, search by approximate machine name or fill missing instructions from general model knowledge. “How should this feel?” receives target-muscle context; sensation diagnosis and safety guarantees remain outside the content. Troubleshooting is limited to fit, range, control and asking gym staff. A stop condition ends technique experimentation and never automatically completes the set.

Weight values in a session were selected by the user in the setup UI. They are not Mat's recommendation and must not be described as safe or appropriate. A replacement machine resets weight rather than transferring it.

Before changing content, review IDs, muscle groups, approved substitutions, equipment/location, wording and source provenance. Record professional review only when it actually occurs. Unknown IDs and unsupported questions must receive explicit uncertainty.
